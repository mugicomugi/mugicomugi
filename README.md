### 実案件

* Cisco ACL保守管理
  * 指定されたプライベートIPアドレスを既存のACLへ追加設定
  * 必要に応じて新規ACL・ACL削除等
  * 使用機器：Cisco Catalyst/Nexus

* Ciscoを用いた基幹ネットワーク構築
  * スタッキング等を用いた冗長構成を意識した新規ネットワーク構築
  * 使用機器：Cisco Catalyst/Nexus

* 防災無線IPネットワーク構築
  * 既設更新・新規敷設などに従事
  * 使用機器：NEC IX/QX

* 施設内防犯カメラ設置に伴うネットワーク構築
  * 固定IPネットワーク <-> IPsec/VPN <-> LTEネットワーク
  * 使用機器：NEC IX/WA
